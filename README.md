
# HydroFoundation Dashboard

AI-based watershed digital twin dashboard.

## Features

- Basin visualization
- Watershed vulnerability map
- Attention visualization
- Basin similarity analysis
- Digital twin representation


## Structure

HydroFoundation_Dashboard/

- app.py
- requirements.txt
- README.md

assets/

- metadata.json
- large_dem.npy
- basin_embeddings.npy
- figures/
- basin_images/


## Run

Install:

pip install -r requirements.txt


Start:

streamlit run app.py
